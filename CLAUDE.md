# CLAUDE.md

Working rules for AI-assisted changes in this repository. They mirror the README; the README wins on conflict.

## Non-negotiable rules

1. **The model reads; the rules decide.** `ingest/receipt.py`, `ingest/extract.py` and `ingest/matcher.py` only turn documents and names into structured data with a confidence. Every e-mail sent, every installment settled and every agreement closed is decided by deterministic code (`rules.py`, `run.py`, `ingest/replies.py`). No date arithmetic, amount matching or sending decision may move into a prompt.
2. **Never collect from someone who may have paid.** A client attachment that neither settled an installment nor was recognised as a non-receipt, a reply that failed to read, or a mailbox that could not be swept each put the collection and the escalation of that case (or of the day) ON HOLD. Do not add a path that collects through a hold.
3. **Unknown means a human.** A structural defect in a notice, a soft doubt (sum, order, an internal e-mail as a client), an unknown sender, a receipt that matches nothing: each becomes a pending agreement, a "check" item or a hold with a stated reason, never a guess.
4. **Idempotency lives in SQLite.** Every send is recorded (`{external_id}`, `#C{n}`, `#ESCALATION`), every processed message too, and a simulation never consumes the real send. A change to the cycle comes with a test that runs the routine twice.
5. **The mailbox is never modified.** Reading needs `Mail.Read`; threaded replies need `Mail.ReadWrite` and fall back to a new message when it is missing. No `PATCH`/`DELETE` on the inbox.
6. **The client-facing text is Portuguese and faithful.** Amounts spelled out, feminine ordinals, the late-payment clause transcribed and never computed. Internal e-mails, logs and code are English.

## Conventions

- Python 3.12, `uv`, `ruff`, `pytest`; tests run offline with fakes.
- `config.py` and `factory.py` are the only modules that read `DEMO_MODE`; business modules receive built collaborators. Demo adapters live in `demo.py`.
- The notice block (`AUTOMATION-DATA v1`) is versioned; a change to its keys is a new version with a parser branch, documented in `docs/NOTICE_FORMAT.md` and in the skill.
- Fixtures hold only invented parties on `.example` domains and case numbers dated 2099 with invalid check digits.
- `fixtures/*.xlsx` and the placeholder PDFs are generated by `scripts/make_fixtures.py`; CI checks they are current.
- Never commit `.env`, `data/`, `.demo/`, `*.sqlite`.
- Commits: English, Conventional Commits, one logical change each, no AI attribution trailers.
